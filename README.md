# JoyTop

Statik sayt (build kerak emas). Asosiy fayl: `index.html`.

## GitHub'ga yuklash
1. github.com → New repository → nomi `joytop`.
2. "uploading an existing file" ni bosing, shu papkadagi barcha fayllarni tashlang, Commit.

## Vercel'ga joylash
1. vercel.com ga GitHub orqali kiring → Add New → Project → `joytop` repozitoriyasini tanlang.
2. Framework: Other. Build command va Output directory bo'sh qoladi → Deploy.
3. Har safar GitHub'ga yangi fayl yuklasangiz sayt o'zi yangilanadi.

## Google Maps
Kalit olingach `config.js` dagi `googleMapsKey` ga yozing va menga ayting: xaritani Google'ga almashtiraman.
